# Checklist de piloto VICAM

Piloto de una semana con al menos un Manager y un Supervisor, datos ficticios o
autorizados para piloto y proceso anterior disponible.

## Antes de iniciar

- [ ] Candidato identificado por versión, commit y cuatro digests.
- [ ] CI, E2E, permisos, offline, accesibilidad y smoke verdes.
- [ ] Restore temporal y rollback de staging probados y fechados.
- [ ] Carga D-76 dentro de puertas o desvíos aceptados por escrito.
- [ ] Monitor externo y alertas de VPS/backup/cola/ClamAV activos.
- [ ] Responsables de soporte, datos, release, backup e incidente asignados.
- [ ] Dispositivos/navegadores objetivo y zonas horarias preparados.
- [ ] Proceso anterior disponible; criterio de retorno comunicado.
- [ ] Participantes capacitados sin compartir credenciales.
- [ ] Formato de hallazgos con severidad, responsable y fecha listo.

## Escenarios diarios

- [ ] Login/sesión y revocación.
- [ ] Cuenta, contacto, visita, cierre y tarea online.
- [ ] Mismo flujo estructurado offline y sincronización sin duplicar.
- [ ] Reasignación y pérdida de acceso del Supervisor.
- [ ] Conflicto visible y resolución Manager.
- [ ] Documento PDF/DOCX/XLSX limpio, falso, EICAR y mayor de 10 MB.
- [ ] Recordatorios, notificación interna y push cuando esté habilitado.
- [ ] Importación repetida y errores por fila.
- [ ] Reporte PDF/XLSX equivalente y expiración.
- [ ] Logout/PIN vencido purgan datos locales.
- [ ] Teclado, foco, lector, 360/390/768/1366/1440 y PWA real.

## Seguimiento

- [ ] Registrar defectos bloqueante/crítico/alto/medio/bajo.
- [ ] Registrar tiempos de formularios, dudas y conectividad.
- [ ] Revisar 5xx, p95, CPU, RAM, disco, WAL, cola, backup y firmas cada día.
- [ ] No pegar tokens, PIN, contraseñas ni documentos en tickets.
- [ ] Mantener lista fechada de correcciones y retest.

## Salida

- [ ] Cero defectos bloqueantes o críticos abiertos.
- [ ] Permisos, propiedad, sync y datos correctos.
- [ ] RPO/RTO y rollback aceptados.
- [ ] Manager y Supervisor completaron escenarios.
- [ ] Aceptación formal firmada o lista fechada de correcciones no bloqueantes.
- [ ] Decisión explícita: salir, extender o volver al proceso anterior.
